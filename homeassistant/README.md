# Dorita (Home Assistant app)

Local control and a live map for iRobot Roomba vacuums, in Home Assistant's sidebar. It runs the
[rest980 server and web UI](https://github.com/crutchcrew/dorita#rest-api-and-web-ui) on top of the
dorita980 library: no iRobot cloud and no port open to your network by default.

See the **Documentation** tab for setup.
